# Hi, I'm Nourhan 👋

### Cybersecurity • Backend Engineering • Secure Software

</div>

I’m a Computer & Communications Engineering student interested in the intersection between **software development and cybersecurity**.

I enjoy understanding how systems work from the inside — building APIs and backend services, testing how applications behave, and looking at the same system from a security perspective.

My interest in cybersecurity started with hands-on learning and CTF challenges, and gradually grew toward **application security and secure software development**. At the same time, I’ve been building my backend skills with **TypeScript, Node.js, NestJS, PostgreSQL, and Prisma**.

What interests me most is the space where these two areas meet: **building software that is not only functional, but secure by design.**

---

### 🔐 What I'm exploring

Right now, I'm particularly interested in:

**Application Security** — understanding common web vulnerabilities, authentication and authorization, and how security issues can emerge from the way applications are designed.

**Secure Backend Systems** — building APIs and services while thinking about input validation, access control, rate limiting, data protection, and secure handling of user-provided content.

**Offensive Security** — learning through CTFs, penetration-testing labs, and trying to understand how an attacker could approach a system.

**DevSecOps** — exploring how security can become part of the development lifecycle rather than something added at the end.

---

### 🛠️ Things I build with

Most of my backend work is centered around **TypeScript and Node.js**, with **NestJS** for building structured server-side applications.

I use **PostgreSQL and Prisma** for data management and have been exploring tools such as **Redis, Docker, Swagger, and Git** along the way.

On the security side, I spend time with **Linux, web security concepts, penetration-testing tools, and CTF challenges**.

---

### 🧩 A little about how I learn

I learn best by building and breaking things.

Instead of only studying a security concept theoretically, I like to put it into practice — build a small application, understand how it works, test its weaknesses, and then think about how it could be made more secure.

You'll find that approach reflected in the projects and experiments on my repositories.
